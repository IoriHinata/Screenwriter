# Локальная языковая модель

Весовые файлы GGUF намеренно не хранятся в Git: они занимают несколько гигабайт. Workflow `Build offline Android APK` умеет скачивать Qwen3-4B Q4_K_M GGUF в отдельный артефакт `qwen3-4b-q4-k-m-gguf`. Модель распространяется отдельно от APK и импортируется в приложении через «Настройки мастерской» → «Выбрать файл GGUF».

Репозиторий модели: https://huggingface.co/Qwen/Qwen3-4B-GGUF
Лицензия весов: Apache-2.0. Перед распространением модели проверяйте актуальные условия лицензии и карточку конкретного файла.

После импорта приложение работает без интернет-разрешения. Модель загружается в оперативную память через нативный движок llama.cpp; для экономии памяти выгружайте её, когда генерация не нужна.
