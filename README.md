# Сценарист — мастерская историй

Android-приложение для создания интерактивных историй с локальным хранением данных.

## Уже реализовано
- создание историй с названием, миром, сеттингом, жанром и персонажами;
- рабочее пространство со сценами и командами: продолжить, изменить последнюю сцену, добавить персонажа, зафиксировать событие, направить сюжет;
- ручное редактирование сцен;
- заметки о персонажах и событиях;
- экспорт в TXT для книжной и сценарной структуры;
- тёмный интерфейс с тёплым акцентом, собственная иконка;
- локальное хранение историй без сервера и без передачи текста в сеть;
- GitHub Actions для сборки APK.

## Важно про нейросеть
Текущая сборка содержит офлайн-черновой генератор на шаблонах, а не полноценную языковую модель. Файл GGUF можно выбрать в настройках как заготовку интерфейса, но сам по себе выбор файла не запускает инференс. Чтобы получить настоящую локальную генерацию, в проект нужно добавить Android-совместимый движок (например, llama.cpp JNI), обработку контекста/токенизации, загрузку модели и подходящие веса. Модельные веса не включены в APK, поскольку даже компактная модель заметно увеличивает размер приложения и требования к оперативной памяти. Библиотека писательских знаний пока не реализована как отдельная поисковая база.

## Сборка
На машине с JDK 17 и Gradle 8.9:
```bash
gradle assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`.

Сборка автоматически запускается при push в `main`. Готовый APK появится в артефактах соответствующего GitHub Actions запуска.
