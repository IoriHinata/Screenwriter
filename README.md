# Сценарист — офлайн-мастерская историй

Android-приложение для писателя. После установки и импорта GGUF-модели приложение работает без интернет-разрешения: рукописи, контекст и генерация остаются на устройстве.

## Что реализовано
- локальные истории, сцены, персонажи, мир, сеттинг и ключевые события;
- редактирование сцен и экспорт TXT;
- локальный движок llama.cpp, собранный для Android через NDK;
- импорт GGUF из памяти телефона через системный выбор файла;
- загрузка модели в native runtime без помещения её весов в Kotlin heap;
- генерация только локальной моделью: нет API-ключей, удалённых запросов и сетевого fallback;
- автоматические unit-тесты и сборка APK через GitHub Actions.

## Модель
Рекомендуемая модель: **Qwen3-4B Q4_K_M GGUF**, лицензия Apache-2.0. Весит примерно 2,5 ГБ и не включается в APK, чтобы не создавать гигантский установщик.

1. Скачай GGUF-файл на устройство (или скачай артефакт модели из GitHub Actions, запустив workflow вручную с параметром `include_model=true`).
2. Открой «Настройки мастерской» → «Выбрать файл GGUF».
3. Дождись копирования и загрузки модели. После этого можно отключить интернет.
4. Для освобождения памяти выгрузи модель и удали исходный скачанный файл, если он больше не нужен.

Внутренняя копия хранится в приватной папке приложения `files/models`. Размер файла модели около 2,5 ГБ; также нужен запас RAM и места под KV-cache. На телефонах с 8 ГБ RAM начни с контекста 4096 токенов. Скорость зависит от CPU и температуры устройства.

## Полностью офлайн
В манифесте отсутствует разрешение `INTERNET`. Приложение не скачивает модель само и не отправляет рукописи на сервер. Скачивание модели выполняется отдельно (например, через браузер); после импорта сеть не нужна.

## Сборка
Требуется JDK 17, Android SDK, NDK 27.2.12479018 и CMake 3.22.1. GitHub Actions отдельно получает исходники llama.cpp и собирает нативную библиотеку:
```bash
gradle --no-daemon testDebugUnitTest assembleDebug
```

APK публикуется как артефакт `screenwriter-offline-debug-apk`. Тесты CI проверяют компиляцию и unit-тесты; для оценки реальной скорости и устойчивости генерации нужен запуск на физическом Android-устройстве.
