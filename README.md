# Сценарист — офлайн-мастерская историй

Android-приложение для писателя. После импорта локальной GGUF-модели рукописи и генерация остаются на устройстве. В манифесте нет разрешения `INTERNET`.

## Возможности
- создание историй и организация проектов по папкам и томам;
- канон мира, сеттинг, жанр, персонажи, ключевые события и авторские заметки;
- сцены с ручным редактированием и сохранением предыдущих версий, которые можно восстановить;
- режимы локального ИИ: продолжить, изменить сцену, добавить героя, событие, сюжетный поворот, диалог, редактор, критик и проверка канона;
- контекстный сборщик: последние сцены, компактный архив старых эпизодов и подбор релевантных фрагментов по словам команды;
- хранение рукописей в локальном JSON-файле с атомарной записью в фоне;
- импорт TXT, Markdown, HTML, RTF, DOCX, PDF, ODT и EPUB;
- экспорт книги или сценария в TXT;
- нативный inference-движок llama.cpp, собираемый для Android через NDK;
- unit-тесты и сборка APK через GitHub Actions.

## Локальная модель
Рекомендуемая модель: **Qwen3-4B Q4_K_M GGUF**, лицензия Apache-2.0, размер около 2,5 ГБ. Модель поставляется отдельно от APK: включение многогигабайтных весов в обычный APK сделало бы установку неудобной и ненадёжной.

1. Скачай файл `Qwen3-4B-Q4_K_M.gguf` на телефон или скачай артефакт модели из GitHub Actions.
2. Открой «Настройки мастерской» → «Выбрать файл GGUF».
3. Дождись импорта и загрузки. Файл копируется в приватную папку приложения, поэтому на время импорта нужно дополнительное место.
4. После загрузки можно отключить интернет: приложение не имеет сетевого разрешения и не отправляет текст наружу.

Для ручного скачивания: [Qwen3-4B-GGUF на Hugging Face](https://huggingface.co/Qwen/Qwen3-4B-GGUF). В GitHub Actions вручную запусти workflow с параметром `include_model=true`, чтобы получить отдельный артефакт весом около 2,5 ГБ.

Начинай с контекста 4096 токенов. 8192 потребует заметно больше памяти. Скорость зависит от процессора, температуры и свободной оперативной памяти; генерация на CPU может быть медленной.

## Импорт документов
Импортёр извлекает текст из TXT/MD/HTML/RTF, DOCX, PDF, ODT и EPUB. Защищённые паролем документы и старый бинарный формат DOC не поддерживаются. Сложная вёрстка, изображения, таблицы и сноски могут быть преобразованы в обычный текст.

## Сборка и проверка
Требуются JDK 17, Android SDK, NDK 27.2.12479018 и CMake 3.22.1. Workflow скачивает исходники llama.cpp и выполняет:
```bash
gradle --no-daemon testDebugUnitTest assembleDebug
```

APK публикуется как артефакт `screenwriter-offline-debug-apk`. Автоматическая сборка подтверждает компиляцию и unit-тесты, но не заменяет запуск модели на физическом устройстве. Скорость и пиковое потребление памяти нужно отдельно проверить на конкретном телефоне.
