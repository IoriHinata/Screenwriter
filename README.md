# Сценарист — мастерская историй

Android-приложение для создания интерактивных историй с локальным хранением данных и подключаемой языковой моделью.

## Возможности
- создание историй с названием, миром, сеттингом, жанром и персонажами;
- сцены, ручное редактирование, события и заметки о персонажах;
- режимы продолжения, переписывания последней сцены, добавления героя, события и сюжетного поворота;
- подключение API, совместимого с OpenAI Chat Completions;
- в каждый запрос ИИ передаются мир, сеттинг, жанр, персонажи, события и **полный текст всех сохранённых сцен по порядку**;
- локальное хранение текста и экспорт в TXT как книги или сценария;
- тёмный интерфейс и собственная иконка приложения;
- автоматическая сборка debug APK через GitHub Actions.

## Подключение языковой модели
Откройте «Настройки» и укажите:
1. адрес API, например `https://api.openai.com/v1`;
2. идентификатор модели, доступный у вашего провайдера;
3. API-ключ.

Нажмите «Сохранить настройки ИИ». Ключ остаётся только в памяти текущего процесса и не записывается в SharedPreferences; после перезапуска его нужно ввести повторно. Не публикуйте ключи в коде, скриншотах или репозитории.

Поддерживается endpoint `/chat/completions`. Для сторонних провайдеров проверьте совместимость формата запроса и ответа. При ошибке API приложение покажет сообщение, а введённая команда не будет молча записана как сгенерированная сцена.

**Контекст:** приложение отправляет все сцены целиком. Если история превысит лимит контекста выбранной модели, провайдер может отклонить запрос; в текущей версии автоматическое суммирование/разбиение на окна не используется, потому что оно может опустить детали. Для очень длинных книг выбирайте модель с большим контекстным окном.

## Ограничения
- Встроенной локальной модели GGUF и native inference-движка пока нет: выбор файла GGUF не запускает генерацию.
- Без API-ключа доступен только простой офлайн-шаблонный генератор, а не нейросеть.
- В текущем релизном кандидате экспорт — TXT; EPUB/DOCX/PDF пока не реализованы.
- Перед публикацией в магазине требуется проверка на реальном устройстве, тестирование конкретного API-провайдера, политики конфиденциальности и release-подпись.

## Сборка
Требуется JDK 17 и Gradle 8.9:
```bash
gradle --no-daemon assembleDebug
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`. При push в `main` GitHub Actions запускает сборку и публикует APK как artifact `screenwriter-debug-apk`.
